# Atlasbound

Atlasbound is an independent fork of Antique Atlas 4. It adds physical atlases with server-owned exploration data for Minecraft 1.21.1 on Fabric and NeoForge.

The original project is [Antique Atlas 4](https://github.com/sisby-folk/antique-atlas). Atlasbound preserves its code and asset notices. See [CREDITS](CREDITS) and [LICENSE](LICENSE).
